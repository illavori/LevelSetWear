# LevelSetWear

Level set wear model on a fixed finite element mesh, implemented as user
elements for Abaqus/Standard.

The worn surfaces of the two bodies in contact are level sets on a fixed
mesh. The mesh and its integration points never move, so the variables
stored at them stay with the material while the surfaces wear.

> **Work in progress.** The code, the examples and the documentation are
> being uploaded.
